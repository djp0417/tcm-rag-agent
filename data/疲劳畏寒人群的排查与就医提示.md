# 疲劳畏寒人群的排查与就医提示

> 本文件整理"总觉得累、怕冷、人变胖"这类常见主诉在中医调理之前
> **应当先排除的几种疾病**，以及相应的检查项目。不构成诊断，仅供就医参考。

## 为什么要先排查

"疲劳、畏寒、体重增加、大便不畅"是中医里很典型的"阳虚""寒湿"表现，
养生调理思路也很明确。但这些表现**同时**是若干常见疾病的典型症状——
如果只按体质调理而漏掉了疾病，就可能耽误治疗。因此规范的做法是：
**先排掉可能模仿"亚健康"的疾病，再谈体质调理。**

## 优先排查：甲状腺功能减退（甲减）

甲减的典型表现与"阳虚"高度重叠：**乏力、怕冷、体重增加、记忆力下降、
反应变慢、皮肤干燥、便秘、月经紊乱、下肢或眼睑浮肿、脱发**。

因此对于**中年女性 + 疲劳 + 畏寒 + 体重增加 + 大便异常**这一组合，
甲状腺功能检查应当排在前面。

- **检查项目**：甲状腺功能（TSH、FT4），必要时加查甲状腺自身抗体（TPOAb、TGAb）
  与甲状腺超声。
- **说明**：TSH 升高、FT4 降低提示甲减；亚临床甲减也可见 TSH 升高而 FT4 正常。
  结果解读与是否治疗应由内分泌科医师判断。

## 其次排查

### 贫血

乏力、面色差、头晕、活动后心慌气短的常见原因。

- **检查项目**：血常规（看血红蛋白、平均红细胞体积），必要时查铁代谢
  （血清铁、铁蛋白）、维生素 B12 与叶酸。

### 血糖异常

乏力、体重变化、口渴多饮都可能与血糖相关。

- **检查项目**：空腹血糖、糖化血红蛋白（HbA1c），必要时做口服葡萄糖耐量试验。

### 血脂异常

- **检查项目**：血脂四项（总胆固醇、甘油三酯、低密度、高密度脂蛋白）。

### 肝肾功能

既是排查，也是后续用药的前提。

- **检查项目**：肝功能（转氨酶、胆红素、白蛋白）、肾功能（肌酐、尿素氮、eGFR）。

### 其他可能性

- **睡眠障碍或睡眠呼吸暂停**：打鼾伴白天嗜睡、晨起头痛者应进一步评估；
- **抑郁或焦虑状态**：可表现为持续乏力、兴趣减退、睡眠改变；
- **慢性感染或自身免疫病**：伴低热、关节痛、皮疹等时需进一步检查。

## 建议的检查组合（基础套餐）

| 项目 | 目的 |
|---|---|
| 甲状腺功能（TSH、FT4） | 排除甲减 —— 与"阳虚"表现最重叠 |
| 血常规 | 排除贫血 |
| 空腹血糖 + 糖化血红蛋白 | 排除糖尿病 / 糖尿病前期 |
| 血脂四项 | 评估代谢状况 |
| 肝功能、肾功能 | 排查与用药安全前提 |
| 血压测量 | 基础生命体征 |

以上为基础筛查，具体项目应由接诊医师根据情况增减。

## 与中医调理的关系

排查与调理**不是二选一**：

1. 先完成基础检查，把"看起来像亚健康、其实是疾病"的情况排掉；
2. 若检查无明显异常，或已在规范治疗中，再按体质与证型做生活方式的调理
   （饮食有节、规律作息、适度运动、情志平和）；
3. 若检查提示异常，应在专科规范治疗的同时，把中医调理作为**配合**手段，
   并且**告知中医师自己的诊断与用药情况**。

## 描述症状时请尽量说清

到医生处就诊时，把这些讲清楚会很有帮助：

- 什么时候开始的，是逐渐加重还是一直如此；
- 具体有哪些不舒服（疲劳的程度、怕冷是全身还是手脚、大便的性状与频次）；
- 体重变化（多久增加了多少）；
- 月经情况（女性）；
- 正在服用的所有药物与保健品，包括中成药和食疗方；
- 家族中有无甲状腺疾病、糖尿病、高血压等病史。
